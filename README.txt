SHARON SAMATHANAM A — ARCHITECTURE PORTFOLIO

QUICK OPEN
Open standalone.html for a single-file version: its CSS, JavaScript, original images, and original PDF are embedded, so it works when downloaded by itself.

EDITABLE SITE
For separately editable HTML, CSS, and JavaScript, extract the complete Sharon-Samathanam-Portfolio folder from the ZIP and open index.html from that extracted folder. index.html explicitly loads the sibling files ./styles.css and ./script.js. Do not open index.html from inside a ZIP preview or download it alone; those actions separate it from its linked files.

INTERACTIONS
Drag the 3D massing model to rotate it. Focus it and use the arrow keys; press R or select Reset to restore the initial view. Filter projects by discipline. Select a project image to open its lightbox; use the left/right arrow keys, on-screen arrows, or Escape to close. On small screens, use the menu button to open navigation. “Save portfolio as PDF” uses your browser's print dialog; choose “Save as PDF”. The original supplied 13-page portfolio is also linked in the résumé section.

CONTENT & PERFORMANCE
The biography, education, four studio projects, project statistics and schedules, design tools, studio experience, contact details, original portrait, project drawings/renders, and artwork from the supplied materials are included. Images are optimized; the editable site lazy-loads its local images. The 3D model is made from CSS 3D transforms and uses no 3D framework. There are no remote font, image, or CDN dependencies.

The supplied material describes Sharon as a fourth-year B.Arch student and does not provide a separate résumé, graduation date, internship, or certification details. The page does not invent those details.
